- Counterpoint 1 : Species 1, Type 0

EXEMPLE 4 — Lexicographic contre Weighted Sum
============================================================

Objectif :
Montrer que Lexicographic et Weighted Sum ne lisent pas les priorités de la même manière.

Cantus Firmus à copier :
60 62 64 67 65 69 67 64 62 60

Traduction :
C4 D4 E4 G4 F4 A4 G4 E4 D4 C4

Solfège :
Do4 Ré4 Mi4 Sol4 Fa4 La4 Sol4 Mi4 Ré4 Do4

Réglages de base :
- Number of voices : 2
- Counterpoint 1 : Species 1, Type 0
- Search Method : BAB
- Mettre "melodic" très haut dans la liste des priorités
- Mettre "fifth" et "octave" plus bas

Solution A :
- Minimization Method : Lexicographic
- Generate

Solution B :
- Minimization Method : Weighted Sum
- Generate

Effet attendu :
En Lexicographic, le coût le plus prioritaire domine fortement.
En Weighted Sum, chaque coût est multiplié par son poids puis additionné.
La solution peut donc faire davantage de compromis.

À regarder dans le terminal :
=== MINIMIZATION METHOD SENT TO FUXCP ===
Lexicographic

puis :
=== MINIMIZATION METHOD SENT TO FUXCP ===
Weighted Sum
